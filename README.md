# TotalQuadro Coordinate Marker

Веб-приложение для работы с картами и координатами в игре «ТоталКвадро».

## 🌟 Возможности

### Основные функции
- **Загрузка карт**: Поддержка PNG, JPG, JPEG, WebP, BMP
- **Управление точками**: Добавление, редактирование, удаление, перетаскивание
- **Ограничения**: Прямоугольник, полигон, круг для ограничения рабочей области
- **Измерения**: Линейка для измерения расстояний в пикселях
- **Экспорт/Импорт**: CSV, JSON, GeoJSON, GPX, KML
- **Автосохранение**: Все данные сохраняются в localStorage

### 🌍 Интеграция с онлайн-картами

Приложение поддерживает три провайдера карт: **Google Maps**, **Яндекс.Карты** и **OpenStreetMap**.

#### Возможности
- Загрузка спутниковых снимков, схем, гибридных карт из любого провайдера
- Автоматическая привязка пиксельных координат к географическим
- Геокодирование адресов (адрес → координаты)
- Обратное геокодирование (координаты → адрес)
- Автоматическое вычисление координат для всех точек
- Экспорт с реальными географическими координатами

#### Провайдеры карт

**1. Google Maps** 🌍
- Спутник, Схема, Гибрид, Рельеф
- Требуется API ключ
- Высокое качество снимков
- Бесплатный лимит: $200/месяц

**2. Яндекс.Карты** 🗺️
- Спутник, Схема, Гибрид
- Требуется API ключ
- Отличное покрытие России и СНГ
- Бесплатный лимит: 25 000 запросов/день

**3. OpenStreetMap** 🌐
- OSM Standard, OpenTopoMap, CartoDB Light
- **Не требует API ключа**
- Полностью бесплатно
- Открытые данные сообщества

#### Как использовать

1. **Выберите провайдера**:
   - Откройте вкладку "🗺️ Карты" в правой панели
   - Выберите провайдера: Google, Яндекс или OSM

2. **Настройте API ключ** (для Google и Яндекс):
   
   **Google Maps**:
   - Перейдите на [Google Cloud Console](https://console.cloud.google.com/)
   - Создайте проект и включите: Maps JavaScript API, Geocoding API
   - Создайте API ключ в разделе "Credentials"
   
   **Яндекс.Карты**:
   - Перейдите на [Яндекс.Карты API](https://developer.tech.yandex.ru/)
   - Получите API ключ
   - Бесплатно: 25 000 запросов/день
   
   **OpenStreetMap**:
   - Просто нажмите "Активировать OSM"
   - API ключ не требуется

3. **Загрузите карту**:
   - Введите адрес или место (например, "Москва, Красная площадь")
   - Настройте параметры:
     - **Зум** (1-21): уровень детализации
     - **Тип карты**: зависит от провайдера
     - **Размер**: ширина и высота в пикселях
   - Нажмите "🗺️ Загрузить карту [Провайдер]"

4. **Работайте с точками**:
   - Все добавленные точки автоматически получают географические координаты
   - Координаты отображаются в списке точек и свойствах
   - При экспорте используются реальные координаты (lat/lon)

#### Примеры использования

**Поиск места по адресу**:
```
Введите: "Санкт-Петербург, Дворцовая площадь"
Зум: 17
Тип: Спутник
Размер: 2048x2048
```

**Загрузка по координатам**:
```
Введите: "55.7558, 37.6173" (Москва, Кремль)
Зум: 16
Тип: Гибрид
```

#### Автоматическая привязка координат

Когда карта загружена из Google Maps:
- Каждая точка автоматически получает координаты lat/lon
- Координаты вычисляются из пиксельных координат и границ карты
- Формула: линейная интерполяция между границами карты
- Точность зависит от зума и размера карты

**Формула конвертации**:
```
lat = north - (pixelY / mapHeight) * (north - south)
lng = west + (pixelX / mapWidth) * (east - west)
```

#### Экспорт с координатами

При экспорте в форматы CSV, GeoJSON, GPX, KML:
- Если карта из Google Maps → используются вычисленные координаты
- Если карта локальная → используются сохранённые координаты (если есть)
- Координаты автоматически добавляются в файлы

**Пример CSV**:
```csv
id;name;x;y;lat;lon;type;comment
abc123;База;512;384;55.755834;37.617298;base;Стартовая точка
```

- `Ctrl+O` — открыть проект

1. **✋ Пан** — панорамирование карты

## 💾 Форматы данных

### Проект (.tqproj)
JSON-файл с полной информацией о проекте:
- Карта (включая границы для онлайн-карт)
- Точки с координатами
- Ограничения
- Слои
- Настройки
- Конфигурация провайдеров карт (Google, Яндекс, OSM)

### Экспорт точек
- **CSV**: таблица с разделителем `;`
- **JSON**: массив точек
- **GeoJSON**: FeatureCollection с Point
- **GPX**: GPS waypoints
- **KML**: Google Earth формат

## 🔒 Безопасность

- API ключи (Google Maps, Яндекс.Карты) хранятся локально в localStorage
- Данные проекта сохраняются только в браузере
- Нет передачи данных на внешние серверы (кроме API карт)
- Рекомендуется ограничить API ключи в консолях провайдеров
- OpenStreetMap не требует API ключа и работает через публичные серверы

## 🤝 Поддержка

При возникновении проблем:

**Google Maps:**
1. Проверьте корректность API ключа
2. Убедитесь, что включены необходимые API в Google Cloud Console
3. Проверьте, что API ключ не имеет ограничений по домену

**Яндекс.Карты:**
1. Проверьте корректность API ключа
2. Убедитесь, что ключ активен в личном кабинете Яндекс
3. Проверьте лимит запросов (25 000/день бесплатно)

**OpenStreetMap:**
1. Убедитесь, что есть подключение к интернету
2. Проверьте, что не превышен лимит запросов (1 запрос/сек)
3. Попробуйте другой сервер тайлов (OpenTopoMap, CartoDB)

**Общие проблемы:**
1. Проверьте консоль браузера на наличие ошибок
2. Очистите localStorage если данные повреждены
3. Перезагрузите страницу

## 🎯 Примеры использования

### Сценарий 1: Игра на местности (Google Maps)
1. Загрузите спутниковый снимок игровой зоны из Google Maps
2. Нарисуйте ограничения (границы игровой зоны)
3. Добавьте точки для объектов (базы, флаги, тайники)
4. Экспортируйте в CSV для передачи участникам

### Сценарий 2: Игра в России (Яндекс.Карты)
1. Выберите провайдера "Яндекс" и введите API ключ
2. Загрузите спутниковый снимок района
3. Добавьте точки для объектов
4. Экспортируйте в GPX для навигатора

### Сценарий 3: Быстрая загрузка без API ключа (OpenStreetMap)
1. Выберите провайдера "OSM" и нажмите "Активировать"
2. Введите адрес места
3. Загрузите карту (OSM Standard или OpenTopoMap)
4. Работайте с точками и экспортируйте в GeoJSON

### Сценарий 4: Планирование маршрута
1. Загрузите карту из любого провайдера
2. Добавьте точки маршрута
3. Измерьте расстояния между точками
4. Экспортируйте в GPX для загрузки в навигатор

### Сценарий 5: Работа с локальной картой
1. Загрузите собственную карту (схема, чертёж)
2. Работайте в пиксельных координатах
3. При необходимости добавьте калибровочные точки
4. Экспортируйте в JSON для архивации
